# Diagramas

Hechos con Archify 3.2. Los HTML se abren con doble clic en el navegador; los JSON son su fuente, por si hay que regenerarlos.

| Archivo | Tipo | Qué muestra |
| --- | --- | --- |
| `arquitectura-explicada.html` | Arquitectura | Quién hace qué: las piezas, los pasos 1 a 6 de cada llegada y A a C de una pregunta al agente |
| `paso-a-paso.html` | Flujo de trabajo | El recorrido por carriles (persona, cámara, servidor, Home Assistant) en tres fases: inscripción, cada llegada y resultado |
| `arquitectura-explicada.json` | Fuente | Candidato de Archify del diagrama de arquitectura |
| `paso-a-paso.json` | Fuente | Candidato de Archify del flujo de trabajo |

Para la sustentación: primero la arquitectura (el mapa) y después el paso a paso (el recorrido).

Los archivos generados por Archify no llevan el encabezado del equipo.
