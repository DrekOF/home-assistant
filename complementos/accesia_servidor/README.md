# AccesIA · servidor

El servidor de AccesIA en la Raspberry Pi (D-22): la API y la web de administración en el puerto 8000, los eventos y el descubrimiento por MQTT, y el servidor MCP del agente, solo para Home Assistant. Necesita los complementos AccesIA · base de datos y Mosquitto.
