# AccesIA · base de datos

PostgreSQL 18 con pgvector para AccesIA. Guarda las personas, las huellas, los eventos y la asistencia. Solo lo usa el complemento AccesIA · servidor, por la red interna de Home Assistant OS: no publica ningún puerto.
